# 24级自编复习题

## 一、选择题

1. **数据结构的组成**  
   什么是数据结构？它包含哪三个方面？  
   复习提示：逻辑结构、存储结构和数据的运算。

2. **算法的基本特性**  
   下列哪一项不属于算法的基本特性？（选项待补充）  
   复习提示：算法是解决特定问题的有限指令序列；基本特性包括有穷性、确定性、可行性、输入和输出。

3. **树结构的特点**  
   下列关于树结构的说法，正确的是哪一项？（选项待补充）  
   复习提示：树结构适合表示具有层次关系的数据。

4. **算法的时间复杂度**  
   使用一个循环遍历含有 n 个元素的序列，求其中的最大值。该算法的时间复杂度是多少？  
   复习提示：每个元素只需访问一次，时间复杂度为 O(n)。

5. **单向非循环链表的删除操作**  
   在单向非循环链表中，指针 p 指向的结点既不是头结点，也不是尾结点。若要删除 p 的后继结点，应如何修改链接关系？  
   复习提示：`p->link = p->link->link;`。若结点由动态内存分配，还应先保存被删除结点的指针，再释放其内存；若维护了尾指针，删除尾结点时还需更新尾指针。

6. **队列的入队与出队**  
   给定一个入队序列，下列哪一种出队情况不可能出现？（入队序列及选项待补充）  
   复习提示：普通队列遵循先进先出原则。

7. **栈的入栈与出栈**  
   给定一个入栈序列，下列哪一种出栈序列不可能出现？（入栈序列及选项待补充）  
   复习提示：栈遵循后进先出原则，可通过模拟入栈和出栈进行判断。

8. **字符串的子串**  
   下列哪一项是字符串 `data` 的子串？（选项待补充）  
   复习提示：子串由原串中连续的字符组成。`data` 的不同非空子串为 `d`、`a`、`t`、`da`、`at`、`ta`、`dat`、`ata`、`data`；空串也是其子串。

9. **无向连通图的边数**  
   一个具有 10 个顶点的无向连通图，至少有多少条边？  
   复习提示：具有 n 个顶点的无向连通图至少有 n − 1 条边，因此本题为 9 条。

10. **排序算法的稳定性**  
    下列哪一种排序算法是不稳定的？（选项待补充）  
    复习提示：通常实现的快速排序是不稳定的排序算法。

### 2. 二维数组与下三角矩阵的存储

（1）二维数组 `B[i][j]` 的下标范围为 `0 ≤ i ≤ n − 1`、`0 ≤ j ≤ m − 1`。若将其按行优先顺序存入下标从 0 开始的一维数组，求元素 `B[i][j]` 对应的一维数组下标。

复习提示：`k = i × m + j`。

（2）若 B 为 n 阶下三角矩阵，将下三角部分按行优先顺序压缩存储到下标从 0 开始的一维数组中，求元素 `B[i][j]` 对应的下标。

复习提示：若包含主对角线，且 `0 ≤ j ≤ i ≤ n − 1`，则 `k = i × (i + 1) / 2 + j`。上三角的零元素通常不逐个存储。

> 原记录中的“行有限”按“行优先”整理；若原题另有存储约定，应以原题为准。

### 3. 哈夫曼树的构建与中序遍历

给定一组权值，使用哈夫曼（Huffman）算法构建哈夫曼树，并写出所构建树的中根序列（中序遍历序列）。

- 权值集合：待补充。
- 构建过程：每次选择权值最小的两棵树合并，新树根结点的权值等于两者之和，重复操作直至只剩一棵树。
- 中序遍历顺序：左子树 → 根结点 → 右子树。
- 注意：需明确左右子树的安排、相同权值时的选择规则，以及结点的输出标记。不同的合法构建方式可能产生不同的中序序列。

### 4. 图的邻接表与深度优先遍历

- 图形：待补充。

## 三、代码题

### 1. 哈希表与线性探测法

编写程序，使用哈希函数建立哈希表，并采用线性探测法处理冲突。

- 关键字序列、表长、哈希函数及输入输出格式：待补充。
- 复习要点：发生冲突后，按顺序探测后续位置，并在到达表尾后循环至表头。
- 探测公式：`H_i(key) = (H(key) + i) % M`，其中 M 为表长，`i = 0, 1, …, M − 1`。
- 编程时应处理表满等边界情况，避免无限循环。

> 原记录中的“线性排查”按“线性探测”整理。

### 2. 任意两座城市之间的最小代价路径

输入城市数 n，以及城市之间的通行代价，编写程序求任意两座城市之间的最小代价路径。

- 代价输入形式、道路是否有向、无直达道路的表示方式及输入输出格式：待补充。
- 复习算法：Floyd 算法。
- 初始化：自身到自身的代价为 0；存在直达道路时记录其代价；无直达道路时设为无穷大。
- 核心更新：`dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`，其中中转城市 k 的循环置于最外层。
- 若要求输出具体路径，还需维护路径恢复信息，例如下一跳矩阵。
- 注意：相加前应判断两段路径是否可达，防止无穷大参与运算导致溢出；若存在可影响该路径的负权环，则不存在有限的最小代价。
- 时间复杂度为 O(n³)，空间复杂度为 O(n²)。
