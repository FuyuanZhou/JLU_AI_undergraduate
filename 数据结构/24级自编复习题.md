## 一、选择题

1. **数据结构的组成**  
   什么是数据结构？它包含哪三个方面？  

2. **算法的基本特性**  
   下列哪一项不属于算法的基本特性？

3. **树结构的特点**  
   下列关于树结构的说法，正确的是哪一项？

4. **算法的时间复杂度**  
   使用一个循环遍历含有 n 个元素的序列，求其中的最大值。该算法的时间复杂度是多少？  

5. **单向非循环链表的删除操作**  
   在单向非循环链表中，指针 p 指向的结点既不是头结点，也不是尾结点。若要删除 p 的后继结点，应如何修改链接关系？  

6. **队列的入队与出队**  
   给定一个入队序列，下列哪一种出队情况不可能出现？

7. **栈的入栈与出栈**  
   给定一个入栈序列，下列哪一种出栈序列不可能出现？

8. **字符串的子串**  
   下列哪一项是字符串 `data` 的子串？
   子串由原串中连续的字符组成。`data` 的不同非空子串为 `d`、`a`、`t`、`da`、`at`、`ta`、`dat`、`ata`、`data`；空串也是其子串。

9. **无向连通图的边数**  
   一个具有 10 个顶点的无向连通图，至少有多少条边？  
   具有 n 个顶点的无向连通图至少有 n − 1 条边，因此本题为 9 条。

10. **排序算法的稳定性**  
    下列哪一种排序算法是不稳定的？ 
    通常实现的快速排序是不稳定的排序算法。

## 二、计算题

### 1. 直接插入排序

给定一个待排序序列，使用直接插入排序完成排序，并写出每一趟排序后的完整序列。


### 2. 二维数组与下三角矩阵的存储

（1）二维数组 `B[i][j]` 的下标范围为 `0 ≤ i ≤ n − 1`、`0 ≤ j ≤ m − 1`。若将其按行优先顺序存入下标从 0 开始的一维数组，求元素 `B[i][j]` 对应的一维数组下标。

复习提示：`k = i × m + j`。

（2）若 B 为 n 阶下三角矩阵，将下三角部分按行优先顺序压缩存储到下标从 0 开始的一维数组中，求元素 `B[i][j]` 对应的下标。

复习提示：若包含主对角线，且 `0 ≤ j ≤ i ≤ n − 1`，则 `k = i × (i + 1) / 2 + j`。上三角的零元素通常不逐个存储。

> 原记录中的“行有限”按“行优先”整理；若原题另有存储约定，应以原题为准。

### 3. 哈夫曼树的构建与中序遍历

给定一组权值，使用哈夫曼（Huffman）算法构建哈夫曼树，并写出所构建树的中根序列（中序遍历序列）。


### 4. 图的邻接表与深度优先遍历

根据题目给出的图写出其邻接表，再根据邻接表写出深度优先搜索（DFS）序列。
