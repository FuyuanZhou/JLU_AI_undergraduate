离散数学这门课内容是可以认为是多个学科入门知识的总和，包括逻辑学，集合论，图论，组合分析，代数系统等，对于此前从未接触过的同学们是很抽象的，而且书中概念，定义，定理**很多很杂**，学习难度参考**线性代数**...

因为这些学问是数据结构与算法的基础，所以建议好好学至少要有一定理解

ppt要注意每年可能有更改。
